# 🌐 Meu Site Acadêmico

## 📌 Visão Geral

Este projeto consiste no desenvolvimento de um site utilizando HTML, CSS e JavaScript, como parte das atividades acadêmicas do curso de Engenharia de Software.

O objetivo é aplicar conhecimentos de desenvolvimento web, organização de código, estruturação de páginas e interatividade, criando uma aplicação acessível e funcional.

## 🛠️ Tecnologias Utilizadas

- HTML5 – Estrutura das páginas.
- CSS3 – Estilização e layout.
- JavaScript – Interatividade e funcionalidades.

## ⚙️ Como executar o projeto

1. Faça o download ou clone este repositório:

   `git clone https://github.com/SEU-USUARIO/meu-site-academico.git`

2. Entre na pasta do projeto:

   `cd meu-site-academico`

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server do Visual Studio Code para executar o site durante o desenvolvimento.
